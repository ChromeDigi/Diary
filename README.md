# My Diary

A simple, private diary that runs in your browser.

## Features

- Write dated entries with a title, mood and text
- Autosaves as you type
- Search all entries
- Export and import backups (JSON)
- Light and dark mode; works on phones

## Privacy

Entries are stored **only in your browser** (localStorage) on the device you use.
They are never uploaded anywhere, including this repository. Clearing your browser
data deletes them, so use **Export backup** regularly.

## Use it

Open `index.html` in a browser. No install or build step needed.
