# Therapy Homework Brief: format and rules

Reference for Phases 9–11. Summarized from the owner's existing workflow (no personal
details here: this repo is public).

## Period
From the day after the previous brief ended through the current therapy session.
Sleep is filed by **night of** (sleep starting that evening), not wake date.

## Layout (about 2 pages)
1. Title ("THERAPY HOMEWORK BRIEF") + exact date range + short subtitle of main domains.
2. Clinical headline: 1–3 sentences on the period's main pattern.
3. Dashboard: 3–4 cards, only metrics the data supports (avg sleep, sleep range,
   short nights, anxiety average, check-ins…). Never a card just to fill space.
4. Sleep table: night of / wake date, total sleep, bedtime, wake, awake time, Apple
   Sleep Score. Estimates clearly marked; unusual nights highlighted subtly.
5. Key-event log: date + what happened + why it matters for therapy. Only important days.
6. Therapy focus: the 2–4 issues worth discussing (skills to revisit, events, sleep…).
7. Overall takeaway: one short synthesis.

## Look
Clean sans-serif, navy/steel-blue headings, pale blue/gray cards, light table fills,
occasional pale green/yellow for normal vs notable values, lots of whitespace.
Delivered as a send-ready PDF plus an editable Word file, e.g.
`Therapy_Homework_Sep28-Oct11_2026`.

## Data integrity rules
- Never invent missing values (scores, anxiety ratings, exercise, dates). Missing stays missing.
- Keep measured data, my report, estimates and interpretation visibly distinct.
- Only say a skill (DEAR MAN, GIVE, FAST, STOP…) was used if it actually was;
  otherwise say the skills need review.
- Facts vs context vs interpretation; keep other people's background brief.
- Brief enough to read in a few minutes; an index of important experiences, not a transcript.
